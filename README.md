# মায়া AI — Android starter

এই project-এ আছে:
- বাংলা text chat
- বাংলা speech-to-text
- Android Text-to-Speech
- “মায়া” personality prompt
- OpenAI Responses API connection

## গুরুত্বপূর্ণ
API key অ্যাপের ভিতরে hard-code করা হয়নি। প্রথম চালু করার পর API key field-এ নিজের key দিয়ে Save করতে হবে।

এই starter সরাসরি Android Studio/Gradle build-এর জন্য। নিরাপদ production app-এ API key সরাসরি mobile app-এ রাখা উচিত নয়; একটি নিজের backend ব্যবহার করা ভালো।

OpenAI-এর নতুন integration-এর জন্য Responses API ব্যবহার করা হয়েছে; পুরোনো Assistants API 26 Aug 2026-এ sunset হয়েছে।
